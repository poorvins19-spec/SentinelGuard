
# Dataset

This folder contains the banking transaction dataset used by SentinelGuard.

## Dataset
creditcard.csv

## Target column
Class

- 0 = Legitimate transaction
- 1 = Fraudulent transaction

## Features
- Time
- Amount
- V1 to V28

The dataset is used for preprocessing, model training,
testing, fraud detection and evaluation.
